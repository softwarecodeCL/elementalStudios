# Traducciones del sitio

El español es el idioma predeterminado de `/`. No hay redirección automática por idioma del navegador. El visitante elige inglés en `/en/` o portugués brasileño en `/pt/`.

## Archivos JavaScript

- `src/i18n/es.js`, `en.js`, `pt.js`: navegación, portada, programas, contacto, pie y metadatos.
- `src/i18n/articles/es.js`, `en.js`, `pt.js`: los dos artículos.
- `src/i18n/assessment/es.js`, `en.js`, `pt.js`: instrucciones, evaluación e informe.
- `src/i18n/assessment/feedback-es.js`, `feedback-en.js`, `feedback-pt.js`: habilidades y explicaciones de respuestas.
- `src/i18n/index.js`: resolución de idioma, enlaces y sustitución de parámetros.

Cada idioma tiene exactamente las mismas claves. Las pruebas comparan su estructura completa y comprueban que las 36 preguntas tengan explicación y habilidades traducidas.

Para cambiar una frase, editar la misma clave en los tres idiomas. Los parámetros como `{count}`, `{score}` o `{total}` deben conservarse. Las explicaciones siguen el identificador numérico estable del banco; si se cambia el orden de las preguntas, actualizar los tres archivos de retroalimentación y la versión del banco.

## Páginas y navegación

Las páginas se generan como HTML estático, con componentes compartidos en `src/components/pages/`. El texto traducido está disponible sin esperar a que JavaScript reemplace el DOM. No se utiliza traducción automática en tiempo de ejecución.

El selector ES / EN / PT conserva la página y el fragmento de sección. Los enlaces internos permanecen dentro del idioma elegido. El diagnóstico comparte el avance local entre idiomas. Las preguntas, opciones, lecturas y audios siguen en inglés porque ese es el idioma evaluado.

Cada página incluye `lang`, título y descripción traducidos, canonical propio y alternates `hreflang` para `es-CL`, `en`, `pt-BR` y `x-default`. El sitemap agrupa las versiones de idioma. La página 404 general permanece en español, está marcada como `noindex` y sus enlaces de idioma llevan a las portadas disponibles.

## Verificación

Las pruebas comprueban rutas, recursos, enlaces, metadatos, claves de traducción, banco de preguntas, puntuación y restauración de intentos.
